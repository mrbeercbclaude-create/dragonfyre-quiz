# Dragonfyre — หาบิลด์ที่ใช่

แบบทดสอบ 30 ข้อ 6 หมวด (ให้คะแนน 7 ระดับ + สถานการณ์ให้เลือกฝั่ง ทุกข้อวัดหลายด้านพร้อมกัน) คิดคะแนน 38 ด้าน สำหรับเพื่อนในเซิร์ฟ ZenixSg (Cisco's Dragonfyre 3C Beta + ม็อดเผ่าเสริม 11 ตัว + พรกรีกของเซิร์ฟ)

ตอบเสร็จได้ 10 บิลด์ เผ่า (Origin) + อาชีพ (Class) + พรจากเทพ (Divine Blessing) จาก 231 เผ่า · 17 อาชีพ · 26 พร พร้อมชื่อบิลด์ คอนเซปต์ วิธีเล่น ค่าพลัง 6 ด้าน จุดอ่อนและวิธีรับมือ เส้นทางต่อยอดด้วยม็อดในแพ็ก และทางแยกของบิลด์

ไม่มี build step:
- `index.html` หน้าเว็บและ CSS
- `addons.js` เผ่า อาชีพ พร จากม็อดเสริม (อ่านจาก jar จริง)
- `data.js` ความชอบ ข้อเสีย และข้อมูลของ Cisco
- `app.js` คำถาม การคิดคะแนน และหน้าผลลัพธ์

คู่มือ (Codex):
- `guide.html` + `guide_data.js` หน้าคู่มือค้นหาได้ ทุกเผ่า อาชีพ พร พร้อมพลังทุกอันแปลไทย
- `Dragonfyre-Codex.docx` ฉบับไฟล์ไว้ส่งให้เพื่อน
- สร้างใหม่: ใน `tools/` รัน `python build_guide.py` แล้ว `python build_docx.py` (คำแปลพลังอยู่ใน `tr1.txt` ถึง `tr3.txt`)
